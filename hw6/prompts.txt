I am developing a web-based image steganography application for a Security Engineering course.

I want to use this project to practice developing a secure Python application primarily through an AI coding agent.

## My initial design notes

- Programming language: Python 3.12
- Web framework: Flask
- Image processing: Pillow
- Frontend: HTML, CSS, and minimal JavaScript
- Steganography algorithm: Least Significant Bit (LSB)
- Initial image format: PNG
- Initial payload format: UTF-8 text
- Development environment: VS Code
- Coding agent: GitHub Copilot Agent mode
- Development port: 5000

## Application functionality

The application should provide two main features:

1. Encoding:
   - Allow a user to upload a PNG image.
   - Allow the user to enter a text message.
   - Hide the message in the image using LSB steganography.
   - Allow the user to download the resulting PNG.

2. Decoding:
   - Allow a user to upload a previously encoded PNG.
   - Detect whether the image contains a message encoded by this application.
   - Extract and display the hidden message.

## Technical requirements

- Implement the LSB algorithm ourselves using Pillow.
- Support UTF-8 text, including non-English characters.
- Support RGB and RGBA images.
- Preserve the original image dimensions and transparency.
- Do not resize, rotate, or otherwise transform images.
- Use a recognizable magic header to identify encoded images.
- Store the message length in the encoded data.
- Include a checksum to detect corrupted payloads.
- Calculate available image capacity before encoding.
- Reject messages that exceed the available capacity.

## Security requirements

- Restrict uploads to PNG images.
- Validate image content rather than trusting filenames or extensions.
- Enforce a 5 MB upload limit.
- Enforce a maximum image dimension of 4000 × 4000 pixels.
- Handle malformed images safely.
- Protect against Pillow decompression-bomb attacks.
- Process uploads in memory using BytesIO.
- Do not save uploaded images or extracted messages to disk.
- Never execute uploaded content.
- Do not use uploaded filenames as filesystem paths.
- Do not enable Flask debug mode.
- Handle errors without exposing sensitive server information.

Authentication is not required for the initial version because this is a local educational application.

## Message format

Use the approved 25-byte header:

- 4-byte magic value.
- 1-byte format version.
- 4-byte big-endian payload length.
- 16-byte SHA-256-based checksum.

Embed the header followed by the UTF-8 message using the least significant bits of RGB channels, traversing pixels in row-major order and channels in R, G, B order.

The checksum is for corruption detection, not authentication.

Calculate available message capacity before encoding.
